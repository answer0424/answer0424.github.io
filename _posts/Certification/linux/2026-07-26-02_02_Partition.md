# 파티션과 저장장치의 기본 구조

## 파티션

#### 개념

- 파티션은 하나의 물리적 디스크를 여러 개의 논리적 디스크로 분할하는 것

<br>

#### 다중 파티션의 장점

- 파티션마다 독립적인 파일 시스템이 운영되기 때문에 파일 점검 시간이 줄어들어 부팅 시간을 단축시킬 수 있음
- 특정 파티션은 파일 시스템이 손상되더라도 다른 파티션에 영향을 주지 않기 때문에 높은 안정성을 보장
- 필요한 파티션만 포맷할 수 있기 때문에 백업과 업그레이드가 편리
- 파티션 상태 정보를 확인할 수 있는 파일은 /proc/partitions
