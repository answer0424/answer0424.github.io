## 리눅스의 특징 및 장단점

#### 특징

1. 오픈 소스 운영체제
2. 멀티 유저(다중 사용자), 멀티 태스킹(다중 작업) 운영체제 - 가상 터미널 환경으로 하나의 모니터에 여러 개의 가상 화면을 두어 화면마다 다른 작업을 실행할 수 있음
3. 다중 스레드를 지원하는 네트워크 운영체제 - 하나의 프로세스 내에서 여러 개의 네트워크 작업을 동시에 처리할 수 있고 네트워크 서버로 사용이 가능
4. 여러 종류의 파일 시스템을 지원하는 운영체제

<br>

#### 장단점

1. POSIX 표준을 준수하여 유닉스와 높은 수준의 호환성을 가짐
2. PC용 운영체제보다 안정적 - 리눅스는 네트워크 사용을 전제로 설계 되었기 때문에 전원을 끄지 않아도 안정적인 운영이 가능
3. 하드웨어 기능을 효과적으로 사용 - 다른 운영체제보다 적은 양의 메모리 사용, SWAP 방식을 통해 램이 부족한 경우 swap 영역을 늘려 메모리 효율성을 높일 수 있음
4. 오픈 소스 운영체제
5. 공개 운영체제적 특성에서 비롯된 기술 지원의 어려움
6. 한글 지원 미흡
7. 보안상 취약점의 노출 가능성
