## 디렉터리 관리 명령어

#### 명령어 pwd

- 현재 작업 중인 디렉터리의 위치를 나타내는 명령어

<br>

#### 명령어  cd

- change directory의 약자로 디렉터리를 이동할 때 사용
- 정대 경로는 시작 위치와 상관없이 경로에 모든 디렉터리를 표시하며 절대 경로의 시작은 /부터 시작
- 상대 경로는 현재 작업중인 디렉터리를 기준으로 함

```bash
cd [상대경로|절대경로] [설정경로]
```

| 설정 경로 | 설명 |
|-|-|
| ~(틸다) | 현재 사용자의 홈 디렉터리로 이동 |
| . | 현재 디렉터리 |
| .. | 현재에서 한 단계 상위 디렉터리 |
| / | 루트 디렉터리 |

<br>

#### 명령어 mkdir

- make directory의 약자로 새로운 디렉터리르 생성할 때 사용하는 명령어

```bash
mkdir [옵션] 디렉터리명 
```

| 옵션 | 설명 |
|-|-|
| -m | 디렉터리를 생성할 때 권한을 설정 |
| -p | 상위 경로 생성 |
| -v | 디렉터리 생성 후 생성된 디렉터리의 메시지 출력 |

<br>

#### 명령어 rmdir

- remove directory의 약자로 디렉터리를 삭제할 때 사용
- 해당 디렉터리 안에 파일이 존재할 경우 삭제되지 않음

```bash
rmdir 디렉터리
```

## 파일 관련 명령어

#### 명령어 ls

- 현재 위치한 디렉터리 파일 목록들을 나타내는 명령어

```bash
ls [옵션] [경로명]
```

| 옵션 | 설명 |
|-|-|
| -a | 히든 파일을 포함한 모든 파일과 디렉터리 표시 |
| -l | 퍼미션 크기, 사이즈 등의 자세한 정보 표시 |
| -d | 지정된 디렉터리의 정보 표시 |
| -r | 알파벳 역순으로 정보 출력 |
| -R | 하위 경로와 그 안에 있는 파일 표시 |

<br>

#### 명령어 cp

- 파일 또는 디렉터리를 복사하는 명령어

```bash
cp [옵션] 원본대상
```

| 옵션 | 설명 |
|-|-|
| -b | 복사 대상 파일이 이미 존재할 경우를 대비하여 백업 파일을 만듦 |
| -f | 복사 대상이 이미 존재하면 복사 대상 파일을 강제로 지우고 복사 |
| -i | 복사 대상이 이미 존재하면 사용자에게 덮어씌울 것인지 유무 확인 |
| -r | 디렉터리를 복사할 경우 하위 디렉터리와 파일을 모두 복사 |


<br>

#### 명령어 rm

- 파일 또는 디렉터리를 삭제

```bash
rm [옵션] 파일명|디레터리명
```

| 옵션 | 설명 |
|-|-|
| -f | 질의 메시지 없이 강제로 파일이나 디렉터리 삭제 |
| -i | 삭제 시 사용자에게 질의 |
| -r | 삭제 디렉터리가 포함하고 있는 하위 디렉터리를 포함하여 모든 파일 삭제 |

<br>

#### 명령어 mv

- 파일 또는 디렉터리를 이동하거나 파일명을 변경할 때 사용

```bash
mv [옵션] 원본대상
```

| 옵션 | 설명 |
|-|-|
| -b | 대상 파일이 이미 있어 지워지는 것을 대비해 백업 파일을 생성 |
| -f | 대상 파일이 이미 있어도 사용자에게 어떻게 처리할지 묻지 않음 |
| -v | 파일이 옮겨지는 과정을 자세히 표시 |

<br>

#### 명령어 touch

- 파일의 크기가 0바이트인 빈 파일을 생성
- 서버의 현재시간으로 파일의 최근 사용한 시간과 최근 수정 시간 등 타임 스탬프를 변경

```bash
touch [옵션] 파일명
```

| 옵션 | 설명 |
|-|-|
| -a | 접근 시간을 변경 |
| -m | 수정 시간을 변경 |
| -c | 시스템 현재 시간으로 파일 시간 정보를 수정 |
| -t 시간정보 | 특정 파일의 시간 정보 변경 |
| -r 파일1 파일2 | 파일1의 시간 정보를 파일2에 동일하게 적용

<br>

#### 명령어 file

- 파일의 종류 및 파일 속성값을 나타내는 명령어

```bash
file [옵션] 파일명
```

| 옵션 | 설명 |
|-|-|
| -b | 파일명은 출력하지 않고 파일 유형만 표시 |
| -f | 파일 목록에서 지정한 파일들에 대해서만 명령을 실행 |
| -z | 압축된 파일의 내용 출력 |
| -i | MIME 타입 문자로 출력 |

<br>

#### 명령어 find

- 현재 디렉터리에서부터 하위 디렉터리까지 주어진 조건의 파일을 찾아 해당 경로에 표시

```bash
find [경로] [옵션] [정규표현식] [파일명]
```

| 옵션 | 설명 |
|-|-|
| -name | 이름을 기준으로 검색 |
| -user | user의 파일이나 디렉터리를 검색 |
| -perm | 지정된 권한의 파일 검색 |
| -type | 파일 유형에 따라 파일 검색 |
| -atime n | n일 이전에 접근한 파일 검색 |
| -exec | 검색된 파일에 수행할 명령어를 지정 |

<br>

#### 명령어 locate

- 파일의 위치를 찾는 명령어

```bash
locate [파일명]
```

## 텍스트 파일 관련 명령어

#### 명령어 cat

- 파일 내용을 출력하는 명령어

```bash
cat [옵션] [파일]
```

| 옵션 | 설명 |
| -n | 각 문장 앞에 번호 표시(비어있는 행 포함) |
| -b | 각 문장 앞에 번호 표시(비어있는 행 제외) |
| -s | 연속되는 2새 이상의 행을 한 행으로 출력 |
| -A | 텍스트 파일에 존재하는 개행 문자나 탭 문자 등을 확인 |

<br>

#### 명령어 head

- 파일의 앞부분을 지정한 만큼 출력하는 명령어

```bash
head [옵션] 파일명
```

| 옵션 | 설명 |
|-|-|
| -c | 출력을 원하는 용량 지정, 지정된 숫자 바이트만큼의 문자 출력 |
| -숫자 또는 -n 숫자 | 출력을 원하는 중 수 지정 |

<br>

#### 명령어 tail

- 파일의 마지막 행을 기준으로 지정한 행까지의 파일 내용 일부를 출력하는 명령어


```bash 
tail [옵션] 파일명
```

| 옵션 | 설명 |
|-|-|
| -c | 출력을 원하는 용량 지정 |
| -숫자 또는 -n 숫자 | 출력을 원하는 수 지정 |
| -f | 지정된 파일에 새롭게 추가되는 파일 내용을 실시간으로 출력 |
| -v | 파일을 출력할 때 파일명을 표시 |
| -q | 파일을 출력할 때 파일명을 표시하지 않음 |

<br>

#### 명령어 more

- 파일을 확인하는 명령어로 파일을 화면 단위로 끊어서 출력하는 명령어
- 위에서 아래 방향으로만 출력되기 때문에 지나간 내용을 다시 볼 수 없음

```bash
more [옵션] 파일명
```

| 옵션 | 설명 |
|-|-|
| -숫자 | 한 페이지에 표시되는 라인 수 |

| 단축키 | 기능 |
|-|-|
| space bar | 다음페이지로 전환 |
| enter | 한 줄씩 출력 |
| ctrl + D | 반 페이지 출력 |
| ctrl + B | 이전 페이지 출력 |
| Q | 종료 |
| /패턴 | 지정한 패턴의 문자열 검색 |

<br>

#### 명령어 less

- 텍스트 파일을 한 번에 한 화면씩 나타내는 명령어
- 기능적으로 more를 확장한 것으로 커서를 파일의 상하좌우로 이동할 수 있음

<br>

#### 명령어 grep

- 파일에서 특정한 패턴 또는 정규 표현식으로 나타낸 단어를 찾는 명령어

```bash
grep [옵션] 문자열 파일명
```

| 옵션 |  설명 |
|-|-|
| -r | 디렉터리 내의 모든 디렉터리와 파일들을 검색하도록 지정 |
| -E | 패턴을 정규 표현식으로 확장 |
| -i | 대문자, 소문자 차이 무시 |
| -v | 검색할 문자열이 포함되지 않은 줄만 출력 |
| -n | 라인 수 출력 |
| -l | 문자열이 포함된 파일명 출력 |

- 명령어 grep 을 이용하여 다양한 내용들을 검색할 수 있음

```bash
# 파일 config에서 'rm'아 들어간 문자열과 행번호를 검색
grep -n 'rm' config 

# 현재 디렉터리에서 'rm'이라는 문자열이 들어간 파일 이름 검색
grep -l 'rm' * 

# 파일 config에서 'a'로 시작하는 행을 검색
grep '^a' config 

# 파일 config에서 'apple'f로 끝나는 행을 검색
grep 'apple$' config 

# 파일 config에서 'appl'로 시작하는 모든 단어를 검색
grep 'appl*' config 

# c로 시작하는 모든 파일에서 'apple'을 포함하는 모든 행 검색
grep 'apple' c* 

# 파일 config에서 'a'나 'b'로 시작되는 모든 행 검색
grep '^[ab]' config
```

<br>

#### 명령어 wc

- 파일의 라인 수, 단어 수, 알파벳 수를 알려주는 명령어

```bash
wc [옵션] 명령어
```

| 옵션 | 설명 |
|-|-|
| -l | 전체 라인 출력 |
| -w | 전체 단어 출력 |
| -c | 전체 문자 수 출력 |

<br>

#### 명령어 sort

- 명령어 결과나 문서 내용을 정렬하는 명령어

```bash
sort [옵션] 정렬할 파일명
```

| 옵션 | 설명 |
|-|-|
| -b | 앞 공백 무시 |
| -o | 저장할 파일 명시 |
| -r | 역순으로 표시 |
| -f | 대소문자 구분하지 않음 |
| -t | 필드 구분자 지정 |
| -u | 중복 행 제거 |
| -m | 정렬 파일 병합 |
| -n | 숫자만 비교 |

<br>

#### 명령어 cut

- 파일에서 특정 필드를 추출해 냄

```bash
cut [옵션] 파일명
```

| 옵션 |  설명 |
|-|-|
| -c | 잘라낼 곳의 글자 위치를 지정, 콤마나 하이픈을 사용하여 지정 |
| -f | 잘라낼 필드 지정 |
| -d | 필드를 구분하는 문자 지정 |
| -s | 대소문자 구분하지 않음 |

<br>

#### 명령어 split

- 하나의 파일을 여러 개의 작은 파일로 분리할 때 사용
- 파일의 내용을 라인 수로 분할할 수도 이있고, 용량 단위로 분할 할 수도 있음
- 주로 디스켓에 파일을 나누어 복사하거나 백업할 때 CD-RW 용량 단위로 분할할 경우 유용

```bash
split [옵션] 파일명
```
| 옵션 | 설명 |
|-|-|
| -b | 파일을 byte 단위로 분할 |
| -l | 파일을 주어진 하인 수 단위로 분할 |

## 파일 비교 명령어

#### 명령어 diff

- 두 개의 파일을 행 단위로 비교하여 다른 부분을 출력하는 명령어
- 두 개의 파일명을 매개변수로 사용하여 화면에 차이점을 나열

```bash
diff [옵션] 파일명1 파일명2 또는 diff [옵션] 디렉터리1 디렉터리2
```

| 옵션 |  설명 |
|-|-|
| -b | 연속된 공백 무시 |
| -i | 대소문자를 구분하지 않음 |
| -s | 두 파일이 같은지 확인 |
| -r | 두 디렉터리의 차이점 출력 |

<br>

#### 명령어 cmp

- 두 개의 파일을 바이트 단위로 비교하여 출력하는 명령어

```bash
cmp [옵션] 파일명1 파일명2
```

| 옵션 | 설명 |
|-|-|
| -b | 두 파일 간의 다른 바이트를 출력 |
| -l | 두 파일 간의 다른 문자 위치와 문자를 출력 |
| -s | 아무것도 출력하지 않고 실행 결과 코드만 반환 |

<br>

#### 명령어 comm

- 두 개의 파일을 줄 단위로 비교하여 출력하는 명령어

```bash
comm [옵션] 파일1 파일2
```

| 옵션 | 설명 |
|-|-|
| -1 | 파일1에만 있는 내용을 제외하고 내용 출력 |
| -2 | 파일2에만 있는 내용을 제외하고 내용 출력 |
| -3 | 파일1과 파일2에 공통으로 존재하는 내용을 제외하고 출력 |

<br>

## 리다이렉션과 정규표현식

#### 리다이렉션

- 표준 입력과 표준 출력의 방향을 재지정하는 것
- 표준 입력/출력/에러가 화면이 아닌 파일로 대체
- 표준 입력 장치는 키보드, 표준 출력 장치는 모인, 표준 에러 장치는 모니터

| 연산자 |  설명 |
|-|-|
| > | 명령을 화면에 출력하는 것이 아니라 프린터나 파일에 출력하도록 전송 |
| >> | 파일이 있는 경우 지정된 파일에 결과를 출력 |
| < | 키보드가 아닌 지정된 파일에서 입력 내용을 읽어옴 |
| >& | 명령의 출력을 다른 명령의 입력으로 보냄 |
| <& | 명령의 입력을 읽고 다른 명령의 출력으로 보냄 |

<br>

#### 파이프

- 둘 이상의 명령을 함께 묶어 출력 결과를 다른 프로그램의 입력으로 전환하는 기능
- 현재 명령의 표준 출력을 다음 명령의 표준입력으로 사용하는 것
- 명령어와 명령어의 연결은 '|' 기호를 사용

<br>

#### 정규표현식

| 기호 | 의미 | 사용 예 | 설명 |
|-|-|-|-|
| ^ | 라인의 첫 글자 | ^a | a로 시작하는 문자 |
| $ | 라인의 끝 글자 | a$ | a로 끝나는 문자 |
| . | 한글자 | a..b | a와 b사이에 2개의 문자가 들어있는 단어 |
| * | 기호 바로 이전의 글자나 정규 표현식이 0회 이상 반복 | abc* | c가 0회 이상 반복 |
| [] | 대체 글자 목록을 []에 나열 | [abc]d | a,b,c 중 한글자라도 반드시 있는 단어 |
| [^] | 대체 못할 글자 목록을 [^]에 나열 | [^abc]d | ad, bd, cd는 포함하지 않음 |
| + | 기호 바로 이전 글자나 정규 표현식이 1회 이상 반복 | abc+ | c가 1회 이상 반복 |
| ? | 기호 바호 이전 글자나 정규  표현식이 없거나 1회만 존재 | abc? | c가 없거나 1회만 존재 |
| () | 부분 정규 표현식의 시작과 끝을 표시 | | |
| \| | \|로 구분된 단어들 중 회소 하나 존재 | | |
