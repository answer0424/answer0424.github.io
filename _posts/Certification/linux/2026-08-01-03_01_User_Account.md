## 리눅스 명령어 개요

#### 명령어 which

- 명령어 경로를 확인하는 명령어
- 명령어 위치를 찾아주거나 alias를 보여주는 명령어
- 사용자가 현재 위치에서 명령을 실행시켰을 때 어떤 명령이 실행되는지를 알고 확인할 수 있음
- $PATH가 설정되어 있는 경로에서만 해당 명령어의 경로를 찾음

```bash
which 명령어
```

---

<br>

#### 명령어 alias

- 자주 사용하는 명령어를 특정 문자로 입력해 두고 명령어 대신 해당 문자를 사용할 수 있게 해주는 명령어

```bash
alias [별명='명령어']

alias m='ls -al | more'
```

<br>

#### 명령어 unalias

- alias 기능을 해제

```bash
unalias m
```

<br>

#### 환경변수 PATH

- PATH는 실행 파일들의 디렉터리 위치를 저장해 놓은 환경변수
- 명령어 입력자의 현재 작업 디렉터리와 상관없이 특정 며령어를 입력하면 PATH 변수에 저장되어 있는 경로에서 해당 명령어를 찾아 실행
- 명령어 echo $PATH는 지정된 PATH 값을 확인할 수 있음

```bash
export 변수명=$변수명:변수값
```
