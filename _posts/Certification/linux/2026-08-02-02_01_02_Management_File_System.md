## 파일 시스템의 개요와 종류

#### 개념과 특징

- 운영체제가 파일을 시스템의 디스크상에 구성하는 방식
- 컴퓨터에서 파일이나 자료를 쉽게 발견 및 접근할 수 있도록 보관 또는 조직하는 체제
- 하드 디스크나 CD-ROM과 같은 물리적 저장소를 관리
- 파일 서버 상의 자료로의 접근을 제공하느 방식과 가상의 형태로서 접근 수단만이 존재하는 방식도 파일 시스템의 범위에 포함
- 리눅스 파일 시스템의 구조

| 블록 | 설명 |
|-|-|
| Super Block | 해당 파일 시슽메 관련 정보 저장 |
| Group Descriptor Table | 각 Block Grou을 관리하는 정보 저장 |
| Block bitmap | 그룹 내에 있는 각 블록의 사용 상태를 나타냄 |
| inode | 파일에 대한 제어 정보 및 데이터 블록 포인터 저장 |

<br>

#### 종류

##### ext

- 리눅스 초기에 사용되던 파일 시스템이며 호환성이 없음

<br>

##### ext2

- ext 파일 시스템의 다음 버전
- 고용량 디스크 사용을 염두에 두고 설계된 파일 시스템

<br>

##### ext3

- ext2의 확장판
- 리눅스의 대표적인 저널링을 지원하도록 확장된 파일 시스템

<br>

##### ext4

- 파일에 디스크 할당 시 물리적으로 연속적인 블록을 할당
- 64비트 기억 공간 제한을 없앰
- 16 TeraByte의 파일을 지원
