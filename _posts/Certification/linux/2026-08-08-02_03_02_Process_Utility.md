## 프로세스 조회, 분석

#### ps(Process Status)

- 현재 실행 중인 프로세스의 상태를 보여주는 명령어
- CPU 사용도가 낮은 순서로 출력

```bash
ps [옵션]
```

| 상태 | 설명 |
|-|-|
| PID | 프로세스 식별 번호 |
| TIY | 프로세스와 연결된 터미널 번호 |
|  TIME | 총 CPU 사용 시간 |
| CMD | 실행 명령어 |

| 옵션 | 설명 |
|-|-|
| a | 현재 실행 중인 모든 프로세스 출력 |
| e | 모든 프로세스 정보 |
| u | 사용자 이름과 프로세스 시작 시간 출력 |
| x | 접속된 터미널뿐만 아니라 사용되고 있는 모든 프로세스들을 출력 |
| l | 자세한 정보 출력 |

```bash
ps ax | grep httpd
```

| 상태 |  설명 |
|-|-|
| USER | 프로세스 소유자명 |
| PID | 프로세스 식별번호 |
| %CPU | CPU 사용 비율의 추정치 |
| %MEM | 메모리 사용 비율의 추정치 |
| VSZ | 페이지 단위의 가상 메모리 사용량 |
| RSS | 실제 사용된 메모리량 |
| TIY | 프로세스와 연결된 터미널 번호 |
| STAT | P: 수행 가능 / 수행 중 <br> R: 현재 실행 상태 <br> S: 잠든 상태 <br> D: I/O 작업이 끝나기를 기다리면서 정지된 상태 <br> T: 정지된 상태 <br> Z: 좀비 프로세스 |
| START | 프로세스 시작 시간 |
|  TIME | 총 CPU 사용시간 |
| COMMAND | 실행 명령어 |

- 좀비 프로세스는 kill 시그널을 받아도 종료되지 않음. 부모 프로세스가 정상적인 종료 처리를 하지 못해서 발생

```bash
ps -l
```

| 상태 | 설명 |
|-|-|
| F | 01: 주기억장치 내에 있음 <br> 02: 시스템 프로세스 <br> 04: 주기억장치 내에서 잠김 <br> 10: 스왑되고 있음 <br> 20: 다른 프로세스에 의해 추적되고 있음 |
| S | R: Running <br> T: Terminated <br> S: Sleeping <br> Z: Stopped <br> W: Waiting <br> I: Intermediated |
| UID | 프로세스 소유자의 Username |
| PPID | 부모 프로세스 PID |
| C | 짧은 시간 동안의 CPU 사용률 |
| PRI | 실행 우선순위 값, 값이 작을수록 우선순위가 높음 |
| NI | NICE 우선순위를 계산할 때 사용되는 nice 값 |
| ADDR | 프로세스의 주기억장치 내의 주소 |
| SZ | 프로세스 크기로 단위는 블록 |
| WCHAN | 프로세스가 대기나 수면 상태에서 기다리는 사건, 실행 중인 프로세스는 공백 |

#### pstree

- 명령어 pstree는 실행 중인 프로세스들을 트리구조로 나타냄

```bash
pstree [옵션]
```

| 옵션 | 설명 |
|-|-|
| -p | 프로세스 ID 표시 |
| -n | 프로세스 ID를 정렬해서 표시 |
| -a | 명령행 인자를 포함한 정보를 트리구조에 표시 |
| -h | 현재 프로세스와 해당 프로세스의 부모 프로세스를 음영으로 강조해서 표시 |

## 종료, 시그널 처리

#### kill

- 프로세스를 종료시킴

```bash
kill [옵션] [시그널 번호 또는 시그널 이름] [PID 또는 %작업번호]
```

| 옵션 | 설명 |
|-|-|
| -l | 시그널 종류 나열 |
| -s 시그널번호 또는 시그널명 | 전달할 시그널의 종류를 지정 |
| -1 | -HU, 프로세스를 재시작 |
| -9 | 프로세스를 강제 종료 |

<br>

#### killall

- 같은 데몬의 여러 프로세서를 한 번에 종료시킬 때 사용
- 프로세스 명으로 연관된 프로세스들을 종료시킴

```bash
killall [옵션] 프로세스명
```

| 옵션 |  설명 |
|-|-|
| -g | 그룹을 지정하여 프로세스를 종료 |
| -i | 프로세스 종료 전 확인 메시지를 표시 |
| -l | 시그널 목록 표시 |
| -v | 상세 정보 표시 |

## 우선순위, 모니터링

#### nice

- 프로세스 사이의 우선순위를 확인하고 우선순위를 변경할 수 있는 명령어
- NI 값을 조정하여 변경

```bash
nice [옵션] 프로세스명
```

| 옵션 | 설명 |
|-|-|
| -n 조정수치, -조정수치, --adjustment 조정수치 | 명령의 우선권에 조정수치를 더함 (-양수값, --음수값)|

- 조정할 수 있는 NI 값의 범위는 -20~19
- 우선순위 0의 값을 가지며 값이 작을수록 우선순위가 높음
- 옵션 -n을 사용하지 않으면 디폴트인 10을 사용
- 조정수치가 생략되면 명령의 우선권은 10만큼 증가
- 일반 사용자는 nice 값을 증가시킬 수 밖에 없으며, root는 nice 값을 감수시켜 우선순위를 높일 수 있음
- 명령어 `nice -10 bash`는 bash 프로세스 NI 값을 10만큼 증가시키는 것이며 값이 증가한다는 것은 우선순위를 낮추는 것 우선순위를 높이는 명령은 `nice --10 bash`임

<br>

#### renice

- 이미 실행중인 프로세스의 우선순위를 변경
- 프로세스 소유자와 루트 권한자만이 명령을 내릴 수 있음

```bash
renice [옵션] NI값 PID
```

| 옵션 | 설명 |
|-|-|
| -p | 프로세스 ID 지정 |
| -u | 사용자명 지정 |
| -g | 프로세스의 GID 지정 |

- 우선순위 변경 시 프로세스 ID, 사용자명, 프로세스 그룹 ID를 사용
- 명령어 nice는 기존 NI값을 증감시키지만, 명령어 renice는 지정한 NI값을 지정
- nice는 양수값에 -, 음수값에 --를 사용하지만 renice는 양수값에 -를 사용하지 않음
- 명령어 `renice -20 3241`은 프로세스 3241의 NI값을 -20으로 변경
