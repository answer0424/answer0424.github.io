## 네트워크 관련 명령어

#### 명령어 ping

- 외부 호스트에 신호를 보내며 신호를 받은 호스트는 응답을 주면서 서로 네트워크가 연결되어 있음을 확인시켜주는 명령어

```bash
ping [옵션] [도메인명 혹은 IP주소]
```

| 옵션 | 설명 |
|-|-|
| -c [요청수] | ping을 보낼 횟수로 생략될 경우 무제한으로 실행 |
| -i [초] | 신호를 보내는 시간 간격으로 생략될 경우 1초 단위로 보냄 |
| -s [패킷 크기] | 전송하는 패킷 크기를 바이트 단위로 보냄 |

<br>

#### 명령어 traceroute

- 목적지 호스트까지의 경로를 표시하고 그 구간의 정보를 기록하는 명령어
- 목적지 호스트까지의 패킷 전송 지역을 측정하거나 목적지 호스트로 향하는 경로상에 어떤 장애가 있는 경우 위치를 파악할 수 있음

```bash
traceroute [도메인명혹은IP주소]
```

<br>

#### 명령어 nslookup

- 도메인명으로 IP주소를 조회하거나 거꾸로 IP 주소로 도메인명을 조회하는 명령어

```bash
nsloopup [옵션] [호스트명]
```

| 옵션 | 설명 |
|-|-|
| -type=레코드 | 레코드 타입을 지정 |

- DNS의 레코드 타입 

| 레코드 | 설명 |
|-|-|
| NS | 도메인의 네임서버 정보 |
| MX | 도메인의 MX 서버 |
| A | 호스트의 IP 주소 |
| CNAME | 별칭으로 부여된 canonical name |
| SOA | 도메인의 start-of-auothority 정보 |
| PRT | IP 주소에 대한 호스트명 |

<br>

#### 명령어 dig

- 명령어 nslookup과 유사한 기능을 가진 명령어로 호스트명에 대한 IP 주소 정보 또는 주소에 대한 호스트명을 조회하는 명령어

```bash
dig [서버명] [호스트명] [질의타입]
```

| 질의 타입 | 설명 |
|-|-|
| a | 도메인 IP 정보 |
| any | 지정된 도메인의 모든 정보 |
| mx | 지정된 도메인의 메일 서버 정보 |
| ns | 네임 서버 정보 |
| soa | SOA 정보 |
