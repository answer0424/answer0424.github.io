## which

> 명령어의 경로를 확인
> 
> 명령어 위치를 찾아주거나 alias를 보여주는 명령어


<br>

## alias

> 자주 사용하는 명령어를 특정 문자로 입력해두고 명령어 대신 해당 문자를 사용

<br>

## unalias

> alias 기능 해제

- -a: 설정된 모든 alias 해제

<br>

## man

> 리눅스에서 사용하는 명령어들의 메뉴얼을 제공

- 옵션
  - -a: 검색된 매뉴얼 페이지를 모두 출력
  - -h: 사용법 출력
  - -f: 키워드와 동일한 man 페이지만 출력
  - -k: 키워드가 포함된 man 페이지 출력
  - -w: 메뉴얼 페이지의 위치를 출력
- 섹션
  - 1: 일반 명령어 관련
  - 2: 시스템 호출 관련
  - 3: C 표준 라이브러리 함수 관련
  - 4: 장치 드라이버 또는 특수 파일 관련
  - 5: 특정 파일 관련
  - 6: 게임과 화면보호기 관련
  - 7: 리눅스 파일 표준, 프로토콜, 시그널 목록 관련
  - 8: 시스템 관리 명령과 데몬 관련
  - 9: 커널 관련

<br>

## info

> 리눅스 명령어의 사용 방법, 옵션 등을 나타냄
> 
> man에 비해 제공되는 명령어가 한정적

<br>

## whatis

> 명령어에 대한 기능을 간략하게 나타냄
> 
> 키워드가 완전 일치해야 검색 가능

<br>

## manpath

> man 페이지의 위치 경로를 검색하여 표시해줌

<br>

## whereis

> 찾고자 하는 명령어의 실행 파일 절대 경로와 소스코드, 설정 파일 및 매뉴얼 페이지를 출력

<br>

## apropos

> 맨 페이지 설명에서 지정한 키워드를 포함하고 있는 명령어

<br>

## useradd

> 계정을 생성하는 명령어로 명령어 adduser와 동일한 기능
> 
> 계정자의 홈 디렉터리는 `/home/계정명`
> 
> 생성된 계정 정보는 /etc/passwd, /etc/shadow, /etc/group에 저장

- -s: 사용자의 로그인 기본 셸을 지정
- -d: 계정의 홈디렉터리 지정
- -e: 사용자의 유효시간 설정
- -G: 계쩡이 속한 그룹 외에 다른 그룹에 계정 추가

<br>

## passwd

> 생성된 계정자의 패스워드를 입력 및 변경
>
> 패스워드는 `/etc/shadow`에 저장

- -S: 계정 상태 표시
- -d: 삭제
- -l: 계정 상태를 lock으로 변경
- -u: lock 해제

<br>

## su

> switch user의 줄임말
> 
> 현재 사용자 계정에서 로그아웃하지 않고 다른 사용자 계정으로 로그인하여 해당 사용자의 권한을 획득

- -, -l, --login: 지정한 사용자의 환경변수를 적용하여 로그인
- -s: 지정된 셸로 로그인


<br>

## usermod

> 디렉터리 `/home`에 위치한 사용자들의 정보를 변경

- -u uid: 새로운 UID 지정
- -g: 새로운 GID 지정
- -G: 새로운 보조그룹 지정
- -d 홈디렉터리: 새로운 홈디렉터리 지정
- -s 셸: 새로운 셸 지정
- -c 주석: 새로운 주석 지정

<br>

## userdel

> 기존 계정 정보를 삭제

<br>

## change

> 패스워드의 만료 정보를 변경하는 리눅스 명령어

<br>

## groupadd

> 새로운 그룹 생성

- -g gid: 그룹에 gid 지정
- -r: 시스템 그룹 생성 시 사용

<br>

## groupdel

> 기존의 그룹을 삭제하는 명령어
>
> 그룹 안에 사용자가 있을 경우 삭제 불가능

<br>

## groupmod

> 그룹의 설정을 변경

<br>

## users

> 시스템에 로그인한 사용자 정보를 출력하는 명령어

<br>

## who

> 현재 시스템에 접속해 있는 사용자들을 조회
> 
> 명령어 whoami는 자신의 접속 정보를 조회 가능
