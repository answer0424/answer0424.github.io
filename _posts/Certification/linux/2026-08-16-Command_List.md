## which

> 명령어의 경로를 확인
> 
> 명령어 위치를 찾아주거나 alias를 보여주는 명령어


<br>

## alias

> 자주 사용하는 명령어를 특정 문자로 입력해두고 명령어 대신 해당 문자를 사용

<br>

## unalias

> alias 기능 해제

- -a: 설정된 모든 alias 해제

<br>

## man

> 리눅스에서 사용하는 명령어들의 메뉴얼을 제공

- 옵션
  - -a: 검색된 매뉴얼 페이지를 모두 출력
  - -h: 사용법 출력
  - -f: 키워드와 동일한 man 페이지만 출력
  - -k: 키워드가 포함된 man 페이지 출력
  - -w: 메뉴얼 페이지의 위치를 출력
- 섹션
  - 1: 일반 명령어 관련
  - 2: 시스템 호출 관련
  - 3: C 표준 라이브러리 함수 관련
  - 4: 장치 드라이버 또는 특수 파일 관련
  - 5: 특정 파일 관련
  - 6: 게임과 화면보호기 관련
  - 7: 리눅스 파일 표준, 프로토콜, 시그널 목록 관련
  - 8: 시스템 관리 명령과 데몬 관련
  - 9: 커널 관련

<br>

## info

> 리눅스 명령어의 사용 방법, 옵션 등을 나타냄
> 
> man에 비해 제공되는 명령어가 한정적

<br>

## whatis

> 명령어에 대한 기능을 간략하게 나타냄
> 
> 키워드가 완전 일치해야 검색 가능

<br>

## manpath

> man 페이지의 위치 경로를 검색하여 표시해줌

<br>

## whereis

> 찾고자 하는 명령어의 실행 파일 절대 경로와 소스코드, 설정 파일 및 매뉴얼 페이지를 출력

<br>

## apropos

> 맨 페이지 설명에서 지정한 키워드를 포함하고 있는 명령어

<br>

## useradd

> 계정을 생성하는 명령어로 명령어 adduser와 동일한 기능
> 
> 계정자의 홈 디렉터리는 `/home/계정명`
> 
> 생성된 계정 정보는 /etc/passwd, /etc/shadow, /etc/group에 저장

- -s: 사용자의 로그인 기본 셸을 지정
- -d: 계정의 홈디렉터리 지정
- -e: 사용자의 유효시간 설정
- -G: 계쩡이 속한 그룹 외에 다른 그룹에 계정 추가

<br>

## passwd

> 생성된 계정자의 패스워드를 입력 및 변경
>
> 패스워드는 `/etc/shadow`에 저장

- -S: 계정 상태 표시
- -d: 삭제
- -l: 계정 상태를 lock으로 변경
- -u: lock 해제

<br>

## su

> switch user의 줄임말
> 
> 현재 사용자 계정에서 로그아웃하지 않고 다른 사용자 계정으로 로그인하여 해당 사용자의 권한을 획득

- -, -l, --login: 지정한 사용자의 환경변수를 적용하여 로그인
- -s: 지정된 셸로 로그인


<br>

## usermod

> 디렉터리 `/home`에 위치한 사용자들의 정보를 변경

- -u uid: 새로운 UID 지정
- -g: 새로운 GID 지정
- -G: 새로운 보조그룹 지정
- -d 홈디렉터리: 새로운 홈디렉터리 지정
- -s 셸: 새로운 셸 지정
- -c 주석: 새로운 주석 지정

<br>

## userdel

> 기존 계정 정보를 삭제

<br>

## groupmod

<br>

<br>

## w

> 현재 접속중인 사용자들의 정보를 나타냄

<br>

## id

> 사용자 계정의 uid, gid, group을 확인

<br>

## groups

> 사용자가 속한 그룹을 확인

<br>

## pwd

> 현재 작업 중인 디렉터리의 위치를 나타냄

<br>

## cd

> change directory의 약자
>
> 디렉터리를 이동할 때 사용

<br>

## mkdir

> make directory의 약자로 새로운 디렉터리를 생성할 때 사용

- -m: 디렉터리를 생성할 때 권한을 설정(default: 755)
- -p: 상위 경로 생성

<br>

## rmdir

> remove directory의 약자로 디렉터리만 사용할 때 사용

<br>

## ls

> 현재 위치한 디렉터리의 파일 목록들을 나타냄

- -a: 히든 파일을 포함한 모든 파일과 디렉터리를 표시
- -l: 자세한 정보 표시
- -d: 지정된 디렉터리의 정보 표시

<br>

## cp

> 파일 또는 디렉터리를 복사할 때 사용

<br>

## rm

> 파일 또는 디렉터리 삭제 시 사용

- -f: 강제 삭제
- -i: 삭제 시 사용자에게 질의
- -r: 하위 디렉터리를 포함하여 모두 삭제

<br>

## mv

> 파일 또는 디렉터리를 이동하거나 파일 명을 변경할 때 사용

<br>

## touch

> 파일 크기가 0바이트인 빈 파일 생성

- -a: 접근 시간 변경
- -m: 수정 시간 변경
- -c: 시스템 현재 시간으로 파일 시간 정보 수정
- -t 시간정보: 특정 파일의 시간 정보 변경
- -r 파일1 파일2: 파일1의 시간 정보를 파일2에 동일하게 적용

<br>

## file

> 파일의 종류 및 파일의 속성값을 나타냄

<br>

## find

> 현재 디렉터리에서부터 하위 디렉터리까지 주어진 조건의 파일을 찾아 해당 경로를 표시

<br>

## locate

> 파일의 위치를 찾는 명령어

<br>

## cat

> 파일의 내용을 출력

- -n: 각 문자 앞에 번호 표시(비어있는 행 포함)
- -b: 각 문자 앞에 번호 표시(비어있는 행 제외)
- -s: 연속되는 2개 이상의 빈 행을 한 행으로 출력 

<br>

## head

> 파일의 앞부분을 지정한 만큼 출력

<br>

## tail

> 파일의 마지막 행을 기준으로 지정한 행까지의 파일 내용 일부를 출력

<br>

## more

> 파일을 확인하는 명령어로 파일을 화면단위로 끊어서 출력
>
> 위에서 아래 방향으로만 진행 가능

<br>

## less

> 텍스트 파일을 한 번에 한 화면씩 나타냄
> 기능적으로 more를 확장한 것

<br>

## grep

> 파일에서 특정 패턴을 찾아냄

- -r: 디렉터리 내의 모든 디렉터리와 파일들을 검색하도록 지정
- -i: 대소문자 차이 무시
- -n: 라인 수 출력

<br>

## wc

> 파일의 라인수, 단어수, 알파벳 수를 알려줌

- -l: 전체 라인 수
- -w: 전체 단어 수
- -c: 전체 문자 수

<br>

## sort

> 명령어 결과나 문서 내용을 정렬

<br>

## cut

> 파일에서 특정 필드를 추출해냄

<br>

## split

> 하나의 파일을 여러 개의 작은 파일로 분리할 때 사용
> 
> 라인 수 단위, 용량 단위로 분할 가능

<br>

## diff

> 두 개의 파일을 행 단위로 비교하여 다른 부분을 출력하는 명령어

<br>

## cmp

> 두 개의 파일을 바이트 단위로 비교하여 출력

<br>

## comm

> 두개의 파일을 줄 단위로 비교하여 출력

<br>

## ping

> 외부 호스트에 신호를 보내며 신호를 받은 호스트는 응답을 주면서 서로 네트워크가 연결되어 있음을 확인시켜줌

<br>

## traceroute

> 목적지 호스트까지의 경로를 표시하고 그 구간의 정보를 기록하는 명령어
> 
> 목적지 호슽까지의 패킷 전송 지역을 측정하거나 목적지 호스트로 향하는 경로 상에 어떤 장애가 있는 경우 위치를 파악할 수 있음

<br>

## nslookup

> 도메인명으로 IP 주소를 조회하거나 거꾸로 IP 주소를 도메인명을 조회하는 명령어

- 레코드 타입
  - NS: 도메인의 네임서버 정보
  - MX: 도메인의 Mail Exchange 서버
  - A: 호스트의 IP 주소
  - CNAME: 별칭으로 부여된 canonical name
  - SOA: 도메인의 start-of-authority 정보
  - PRT: IP 주소에 대한 호스트명

<br>

## dig

> 명령어 nslookup과 유사한 기능이며 호스트명에 대한 IP 주소 정보 또는 IP 주소에 대한 호스트명을 조회

<br>

## host

> 호스트 명을 알고 있으나 IP 주소를 모르거나 그 반대의 경우에 사용

<br>

## hostname

> 시스템 이름을 확인하거나 변경할 때 사용

- -a: 별칭 출력
- -d: 도메인명 출력
- -F: 지정한 파일에서 호스트명을 설정

<br>

## shutdown

> 시스템을 종료하거나 재부팅
>
> 저장되지 않은 데이터를 디스크에 저장하고 모든 파일 시스템을 mount 시킨 후에 시스템을 종료

- -r: 재부팅
- -h: 시스템 종료
- -c: 진행중인 shutdown 취소
- -k: 경고 메시지만 출력하고 shutdown하지 않음
- -t sec: 지정 시간에 시스템 재시동

<br>

## init

> shutdown과 동일한 기능

- 0: 지금 즉시 종료
- 1: 단일 사용자 복구 모드로 재시작
- 2: 다중 사용자 모드
- 3: 텍스트 모드로 재시작
- 4: 사용 안함
- 5: X-윈도우 모드로 재시작
- 6: 재가동 모드

<br>

## reboot

> 시스템 재부팅

- -f: 강제 재부팅

<br>

## halt

> 시스템을 종료하는 명령어

<br>

## cal

> 시스템에 설정된 달력을 출력

<br>

## date

<br>

## clear

> 터미널 내용을 지움

<br>

## tty

> 햔재 사용하고 있는 단말기 장치의 경로명과 파일명을 나타냄

<br>

## time

> 프로그램이 수행되는 데 걸리는 시간을 측정하여 출력

<br>

## chown

> 명령어 chown은 파일과 디렉터리의 사용자 소유권과 그룹 소유권을 변경

<br>

## chgrp

> change group의 약자로 그룹 소유권을 변경

<br>

## chmod

> 파일이나 디렉터리의 접근 허가권을 변경

<br>

## umask

> 새로 생성되는 파일이나 디렉터리의 기본 허가권 값을 지정
>
> 파일의 기본 권한은 666, 디렉터리의 기본 권한 777
>
> 예를 들어 umask가 022인 경우 디폴트 파일 권한 644(666-022), 디렉터리의 권한은 755(777-022)

<br>

## quotaoff

> 쿼터 서비스를 비활성화

<br>

## quotacheck

> 파일 시스템의 디스크 사용 상태를 검색

<br>

## edquota

> 편집기를 이용하여 사용자나 그룹에 디스크 사용량을 할당

<br>

## setquota

> 편집기가 기반이 아닌 명령행에서 직접 사용자나 그룹에 디스크 사용량을 할당하는 명령어

<br>

## mount/umount

> 마운트는 특정 디바이스를 특정 디렉터리처럼 사용하기 위해 장치와 디렉터리를 연결하는 것
>
> 리눅스는 PnP 기능을 지원하지만 지원하는 하드웨어가 많지 않으므로 시스템 부팅 후 수동으로 마운트해서 사용하고 사용이 끝난 후에는 언마운트시킴

<br>

## eject

> 이동식 보조기억장치 등과 같은 미디어를 해제하고 장치를 제거

<br>

## fdisk

> 새로운 파티션의 생성, 기존 파티션의 삭제, 파티션의 타입 결정 등의 작업을 수행할 수 있음
>
> fdisk 프로그램은 한 번에 한 디스크에 대해서만 작업을 수행
>
> fdisk를 실행하기 위해서는 어떠한 디스크의 파티션을 나눌 것인지 알려줘야 함

- p: 디스크 정보 표시
- n: 파티션 생성
- t: 파티션 속성 지정
- d: 파티션 삭제
- w: 변경된 파티션 정보 저장
- q: 파티션 설정 작업 종료

<br>

## mkfs

> 리눅스 파일 시스템을 생성
>
> fdisk로 하드디스크의 파티션을 나눈 후 해당 파티션에 맞는 파일 시스템을 생성

<br>

## fsck

> 파일 시스템의 무결성을 점검하고 대화식으로 복구
>
> 단계
> > 오류에 대한 저널 로그 점검
> > i-node, 간접 데이터 블록 등을 점검
> > 파일 크기의 점검과 디렉터리 항목의 점검

<br>

## du

> Disk Usage의 약자로 디렉터리별로 디스크 사용량 확인 가능

<br>

## df

> 시스템에 마운트된 하드 디스크의 용량을 파티션 단위로 사용량을 확인

<br>

## ps

> 현재 실행 중인 프로세스의 상태를 보여줌
>
> CPU 사용도가 낮은 순서로 출력

- a: 현재 실행 중인 모든 프로세스 출력
- e: 모든 프로세스 정보
- u: 사용자 이름과 프로세스 시작 시간 출력
- x: 접속된 터미널뿐만 아니라 사용되고 있는 모든 프로세스들을 출력
- l:  자세한 정보 출력

<br>

## pstree

> 실행 중인 프로세스들을 트리 구조로 나타냄

<br>

## kill

> 프로세스를 종료시킴

<br>

## killall

> 같은 데몬의 여러 프로세서를 한번에 종료시킴

<br>

## nice

> 프로세스 사이의 우선순위를 확인하고 우선순위를 변경할 수 있음
>
> NI 값을 조정하여 프로세스의 우선순위를 변경(-20~19)
>
> 우선순위는 0의 값을 가지며 값이 작을 수록 우선순위가 높음
>
> 옵션 -n을 사용하지 않으면 디폴트인 10을 사용

<br>

## renice

> 이미 실행 중인 프로세스의 우선순위를 변경
>
> 프로세스 소유자와 로트 권한자만이 명령을 내릴 수 있음
>
> nice는 기존 NI값을 증감시키지만, renice는 지정한 NI값을 설정

<br>

## top

> 리눅스 시스템의 운영 상태를 실시간으로 모니터링하거나 프로세스 상태 확인

<br>

## jobs

> 작업이 중지된 상태, 백그라운드로 진행 중인 상태, 변경되었지만 보고되지 않은 상태 등을 표시

<br>

## nohup

> 프로세스가 중단되지 않고 백그라운드로 작업을 수행할 수 있게 해줌
> 
> 사용자가 로그아웃하거나 작업 중인 터미널 창이 닫혀도 계속 작업 가능
>
> 명령행 뒤에 `&`을 명시

<br>

## lpr

> 프린터 작업 요청

<br>

## lpq

> 프린터 큐에 작업 목록 출력

<br>

## lprm

> 프린터 큐에 대기 중인 작업을 삭제
>
> 취소할 프린트 작업 번호를 입력

<br>

## lpc

> 프린터나 프린터 큐를 제어

<br>

## lp

> 프린터 작업 요청

<br>

## lpstat

> 프린터 큐의 상태 확인

<br>

## cancel

> 프린터 작업 취소
