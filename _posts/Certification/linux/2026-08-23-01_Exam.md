## 1번

```
/data 디렉터리를 여러 사용자가 자유롭게 파일 생성이 가능하나 삭제는 본인 소유의 파일만 가능한 공유 디렉터리로 만들려고 한다
```
- 해설: 특수 권한 중 Sticky bit는 여러 사용자가 쓰기 가능한 디렉터리에서 소유자가 아닌 다른 사용자의 파일 삭제를 막기 위한 것
- 정답: chmod o+t /data

## 5번

```
소프트웨어 RAID 복구 시 사용하는 명령어로 적절한 것?
```

- 해설

## 6번

```
(): 물리적인 디스크의 오류를 2개까지 허용하도록 구성
(): 분할된 파티션의 용량을 손쉽게 증설이 가능하도록 구성
```

- 해설:
  - LVM: 논리 볼륨 관리 시스템, 여러 물리적 디스크를 하나의 논리 볼륨으로 묶어 사용하는 등 디스크 관리를 유연하게 할 수 있음
  - RAID5: 최소 3개 이상의 하드디스크가 있어야 하며 일반적으로 5개 이상의 하드디스크로 구성됨, 하드디스크에 오류가 발생하면 Parity를 이용하여 데이터를 복구할 수 있음
  - RAID6: RAID5 방식은 하나의 디스크가 고장나도 복구할 수 있지만 두 개의 디스크가 동시에 고장난 경우에는 복구할 수가 없음, RAID6 방식은 RAID5를 개선한 방법으로 2개의 디스크가 동시에 고장나도 데이터에는 이상이 없도록 하는 방식

## 8번

```
RAID 레벨 중 2개 이상의 디스크 장애 시에도 데이터 복구가 가능한 레벨은?
```

- 해설: RAID 6는 각 디스크에 두 개의 패리티 데이터를 기록하므로 디스크가 최대 2개까지 고장나도 데이터 손실이 발생하지 않음
- 정답: RAID6

### 9번

```
LVM 구성 단계로 옳은 것은?
```

- 해설: PV(실제 디스크 또는 파티션) -> VG(PV를 모은 그룹) -> LV(VG에서 논리적으로 나눈 볼륨)
- 정답: PV -> VG -> LV

## 10번

```
LVM의 장점으로 옳은 것?
```

- 해설 및 정답
  - 디스크 공간을 유연하게 할당할 수 있음
  - 시스템을 종료하지 않고 온라인 상태에서 볼륨의 크기를 변경할 수 있음
  - 여러 개의 물리 디스크를 하나의 논리적 볼륨으로 통합할 수 있음
  - 참고: LVM은 백업 기능은 없음

## 14번

```
ihduser 사용자는 본인이 설정한 Alias를 다음 로그인해서도 계속 사용하려고 한다
```

- 해설
  - ~/.bash_history: 사용자의 bash 셸 명령 실행 기록을 저장하는 파일
  - ~/.bash_profile: 환경변수와 bash가 수행될 때 실행되는 프로그램을 제어하는 지역적인 시스템 설정과 관련된 파일
  - ~/.bash_logout: 셸이 종료할 때 실행하는 파일로 로그아웃 시 적용되어야 하는 지역적 시스템 설정값을 가진 파일
- 정답
  - ./bashrc
