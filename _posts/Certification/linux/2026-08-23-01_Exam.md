## 1번

```
/data 디렉터리를 여러 사용자가 자유롭게 파일 생성이 가능하나 삭제는 본인 소유의 파일만 가능한 공유 디렉터리로 만들려고 한다
```
- 해설: 특수 권한 중 Sticky bit는 여러 사용자가 쓰기 가능한 디렉터리에서 소유자가 아닌 다른 사용자의 파일 삭제를 막기 위한 것
- 정답: chmod o+t /data

## 5번

```
소프트웨어 RAID 복구 시 사용하는 명령어로 적절한 것?
```

- 해설
  - fsck: 파일시스템의 일관성 검사 및 복구
  - pvcreate: LVM에서 사용할 물리 볼륨 생성
  - mkfs: 디스크나 파티션에 파일시스템 생성
- 정답: mdadm

## 6번

```
(): 물리적인 디스크의 오류를 2개까지 허용하도록 구성
(): 분할된 파티션의 용량을 손쉽게 증설이 가능하도록 구성
```

- 해설:
  - LVM: 논리 볼륨 관리 시스템, 여러 물리적 디스크를 하나의 논리 볼륨으로 묶어 사용하는 등 디스크 관리를 유연하게 할 수 있음
  - RAID5: 최소 3개 이상의 하드디스크가 있어야 하며 일반적으로 5개 이상의 하드디스크로 구성됨, 하드디스크에 오류가 발생하면 Parity를 이용하여 데이터를 복구할 수 있음
  - RAID6: RAID5 방식은 하나의 디스크가 고장나도 복구할 수 있지만 두 개의 디스크가 동시에 고장난 경우에는 복구할 수가 없음, RAID6 방식은 RAID5를 개선한 방법으로 2개의 디스크가 동시에 고장나도 데이터에는 이상이 없도록 하는 방식

## 8번

```
RAID 레벨 중 2개 이상의 디스크 장애 시에도 데이터 복구가 가능한 레벨은?
```

- 해설: RAID 6는 각 디스크에 두 개의 패리티 데이터를 기록하므로 디스크가 최대 2개까지 고장나도 데이터 손실이 발생하지 않음
- 정답: RAID6

### 9번

```
LVM 구성 단계로 옳은 것은?
```

- 해설: PV(실제 디스크 또는 파티션) -> VG(PV를 모은 그룹) -> LV(VG에서 논리적으로 나눈 볼륨)
- 정답: PV -> VG -> LV

## 10번

```
LVM의 장점으로 옳은 것?
```

- 해설 및 정답
  - 디스크 공간을 유연하게 할당할 수 있음
  - 시스템을 종료하지 않고 온라인 상태에서 볼륨의 크기를 변경할 수 있음
  - 여러 개의 물리 디스크를 하나의 논리적 볼륨으로 통합할 수 있음
  - 참고: LVM은 백업 기능은 없음

## 14번

```
ihduser 사용자는 본인이 설정한 Alias를 다음 로그인해서도 계속 사용하려고 한다
```

- 해설
  - ~/.bash_history: 사용자의 bash 셸 명령 실행 기록을 저장하는 파일
  - ~/.bash_profile: 환경변수와 bash가 수행될 때 실행되는 프로그램을 제어하는 지역적인 시스템 설정과 관련된 파일
  - ~/.bash_logout: 셸이 종료할 때 실행하는 파일로 로그아웃 시 적용되어야 하는 지역적 시스템 설정값을 가진 파일
- 정답
  - ./bashrc

## 17번

```
다음 중 새롭게 생성된 파티션을 /etc/fstab 파일에 등록하는 형식으로 알맞은 것은?
```

- 해설: 
  - `[파일_시스템_장치] [마운트_포인트] [파일_시스템_종류] [옵션] [덤프] [파일체크_옵션]`
  - 옵션 중 defaults는 rw, nouser, auto, exec, suid 속성을 모두 가지고 있기 떄문에 default에 s가 붙음
- 정답: `/dev/sdb1 /home2 ext4 defaults 1 1`

## 18번

```
/etc/fstab 설정을 변경한 후, 시스템 재부팅 없이 변경 내용을 적용하려면 어떤 명령어를 사용해야 하는가?
```

- 해설: mount -a 명령어는 재부팅 없이 즉시 /etc/fstab에 있는 모든 파일시스템을 마운트
- 정답: `mount -a`

## 20번

- 정답: /etc/apt/sources.list

## 22번

```
리눅스가 부팅을 시작하면 커널이 최초의 프로세스인 () 프로세스를 발생시키는데, 할당되는 PID는 ()이다
```

- 해설: init은 리눅스 커널 부팅 후 가장 먼저 실행되는 프로세스로, 시스템 초기화 및 서비스 관리를 담당하는 전통적인 시스템이며, systemd는 init을 대체하기 위해 등장한 시스템이자 데몬
- 정답: systemd, 1

## 23번

```
리눅스 시스템에서 현재 실행 중인 프로세스를 복제하여 새로운 프로세스를 생성하는 시스템 호출은 무엇인가?
```

- 해설
  - execve(): 다른 프로그램을 실행하고 자신은 종료
  - exit(): 프로그램 실행을 정상적으로 종료시키거나 오류가 발생하여 강제 종료
  - wait(): 자식 프로세스의 종료를 기다려 줌
- 정답: fork()

## 26번

```
Linux 시스템에서 사용되고 있는 메모리 양과 사용가능한 메모리양, 공유 메모리와 가상 메모리에 대한 정보를 볼 수 있는 명령어는?
```

- 해설

```
디스크 UUID를 확인하는 명령어는 무엇인가?
```

- 해설: UUID는 시스템의 다양한 객체를 중복 없이 고유하게 식별하는 데 사용되는 128비트의 공유한 갑 blkid 명령어는 디스크 및 파티션의 UUID, 파일 시스템 유형 등 정보를 출력

## 28번

```
로그아웃과 같이 터미널에서 접속이 끊겼을 때 보내지는 시그널
데몬 관련 환경설정 파일을 변경시키고 변화된 내용을 적용하기 위해 재시작할 때 시그널이 사용
```

- 해설
  - SIGINT: `ctrl+c`를 눌렀을 때 발생하는 신호로 Foreground 프로세스 그룹의 모든 프로세스를 종료
  - SIGSTOP: 프로세스의 실행을 즉시 일시 중단하는 신호
  - SIGQUIT: `ctrl+w`를 눌렀을 때 발생하는 신호로 SIGINT와 같지만 종료하면서 Core Dump를 발생시킴
- 정답: SIGHUP

## 30번

```
다음 중 백그라운드 수행 중인 프로세스를 확인하는 명령어?
```

- 해설
  - bg: 현재 실행 중인 프로세스를 백그라운드 작업으로 전환하는 명령어

## 33번

다음중 실행되지 않는 명령은?

```
[ihd@www ~]$ ls -l
total 4
-rw-rw-r-- 1 ihd 1222 JAN 11 09:15 joon.txt
drwxrwxr-x 1 ihd ihd 6 Jan 11 21:05 lin
```

- 해설
  - ln: 디렉터리에 생성 불가, 동일 파일 시스템에서만 가능(`ln [원본파일] [새로운링크파일]`)
  - ln -s: 디렉터리에도 생성 가능, 다른 파일 시스템 간 링크 가능(`ln -s [원본파일또는디렉터리] [새로운심볼릭링크]`)
- 정답: ln lin 1
