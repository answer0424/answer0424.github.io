## 셸의 개념과 종류

#### 개념

- 명령어 해석기
- 사용자의 명령어를 해석하여 커널에 전달
- 커널과 사용자 간의 대화식 인터페이스를 제공
- 강력한 스크립트 언어

<br>

#### 종료

- Bourne Shell과 C Shell 계열로 나뉨

##### Bourne Shell

- 본셸 - /bin/sh
- 콘셸 - /bin/ksh
- 배쉬셸 - /bin/bash
- 지셸 - /bin/zsh

<br>

##### C Shell

- C셸 - /bin/csh
- tc셸 - /bin/tcsh

---

## 셸 변경

#### 명령어 chsh

- 일반 사용자 환경에서 셸 변경 시 사용

```bash
chsh [옵션] 계정명 셸
```

| 옵션 | 설명 |
|-|-|
| -s | 지정하는 셸을 앞으로 사용할 로그인 셸로 변경 |
| -l | /etc/shells 파일 안에 지정된 셸을 나열 |

<br>

#### 명령어 usermod

- 관리자 환경에서 지정된 계정의 정보를 변경할 때 사용하는 명령어

```bash
usermod [옵션] 계정명
```
