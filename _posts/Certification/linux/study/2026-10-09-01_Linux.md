# 리눅스 일반

## 리눅스 특징 및 장단점

- 오픈 소스 운영체제
- 멀티유저, 멀티태스킹 운영체제
- 다중 스레드를 지원하는 네트워크 운영체제
- 여러 종류의 파일 시스템을 지원
- 리눅스는 POSIX 규격을 따름
- PC용 운영체제보다 안정적
- 하드웨어 기능을 효과적으로 사용

<br>

## 운영체제의 구조와 기능

- 정의: 우리가 컴퓨터를 사용할 때 사용하기 쉽게 여러가지 프로그램들을 합쳐놓은 것

<br>

## 리눅스 배포판

- 안녕 리눅스: 한글판 리눅스
- debian -> Ubuntu
- redhat -> CentOS
- suse -> open Suse

<br>

## 리눅스의 역사

1. 1965년 MIT와 벨 연구소 프로젝트 진행(실패)
2. 1969년 던 켄 톰이 UNIX를 개발
3. 1971년 UNIX를 C언어로 재작성
4. 1985년 리처드 스톨만 GNU 프로젝트를 진행하면서 오픈소스로 전환
5. 1987년 MINIX 개발
6. 1991년 리누스 토발즈가 GNU 시스템에 적합한 커널 개발
7. 1994년 리눅스 커널 1.0 발표
8. 1996년 리눅스 커널 2.0 발표
