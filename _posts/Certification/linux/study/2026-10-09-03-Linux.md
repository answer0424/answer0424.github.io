# 리눅스 명령어 개요

## 명령어와 관련된 명령어

#### which

- 명령어의 경로를 확인

```bash
which ls
```

<br>

#### alias

- 자주 사용하는 명령어를 특정 문자로 사용할 수 있게 해줌

```bash
alias ll='ls -al'
```

<br>

#### unalias

- alias로 등록한 문자를 해제하는 명령어

```bash
unalias ll
```

<br>

#### PATH

- 명령어의 실행 파일들의 위치를 저장해 놓은 환경변수

<br>

#### echo

- 화면에 무언가를 출력

```bash
echo $PS1
```

---

## 도움말 관련 명령어

#### man

- 사용하는 명령어들의 메뉴얼을 제공

```bash
man ls
```

<br>

#### info

- 명령어의 사용 방법, 옵션 등을 제공

<br>

#### whatis

- 명령어에 대한 기능을 간략하게 나타냄

<br>

#### manpath

- man 페이지의 위치 경로를 검색하여 표시

<br>

#### whereis

- 명령어의 실행 파일 절대 경로와 소스코드, 설정 파일 및 메뉴얼 페이지를 찾아 출력

<br>

#### apropos

- man 페이지 설명에서 지정한 키워드를 포함

---

## 사용자 생성 명령어

#### useradd

- 계정을 생성

```bash
useradd test01
```

<br>

#### passwd

- 생성된 계정자의 패스워드를 입력 및 변경

```bash
passwd test01
```

<br>

#### su

- switch user의 줄임말로 다른 사용자 계정으로 로그인

```bash
su - root
```

<br>

## 사용자 관련 파일

#### /etc/default/useradd

- useradd로 사용자 계정을 추가할 때 기본으로 설정되는 정보가 저장된 파일

<br>

#### /etc/passwd

- 사용자 정보를 가지고 있는 파일, 사용자가 로그인할 때 사용

<br>

#### /etc/shadow

- 사용자의 패스워드 정보가 암호화되어 있는 파일

<br>

#### /etc/login.defs

- 사용자 계정 설정과 관련된 기본값을 정의한 파일

---

## 사용자 계정 관리

#### usermod

- 사용자들의 정보를 변경하는 명령어

```bash
# 사용자의 설명 부분을 변경
usermod -c test test01
```

<br>

#### userdel

- 계정 정보를 삭제

```bash
userdel test01
```

<br>

#### chage

- 패스워드의 만료 정보를 변경

---

## 그룹 관리

#### /etc/group

- 그룹에 대해 정의되어 있는 파일

<br>

#### /etc/gshadow

- 그룹의 패스워드 정보가 암호화되어 있는 파일

<br>

#### groupadd

- 새로운 그룹을 생성

<br>

#### groupdel

- 그룹을 삭제

<br>

#### groupmod

- 그룹의 설정을 변경

---

## 디렉토리 관리 명령어

#### pwd

- 현재 작업 중인 디렉터리의 위치를 나타냄

<br>

#### cd

- change directory의 약자로 디렉터리를 이동할 때 사용

<br>

#### mkdir

- make directory의 약자로 새로운 디렉터리를 생성할 때 사용

```bash
mkdir dir
```

<br>

#### rmdir

- remove directory의 약자로 디렉터리만 삭제할 때 사용

```bash
rmdir dir
```

---

## 파일 관련 명령어

#### ls

- 디렉터리의 파일 목록들을 나타냄

```bash
# a:숨겨진 파일까지 출력 / l: 자세하게 출력
ls -al
```

<br>

#### cp

- 파일 또는 디렉터리를 복사

<br>

#### rm

- 파일 또는 디렉터리를 삭제

```bash
# r:파일이든 디렉토리든 상관없이 삭제 / f:강제로 삭제
rm -rf dir
rm file
```

<br>

#### mv

- 파일 또는 디렉터리르 이동하거나 파일 명을 변경할 때 사용

<br>

#### touch

- 파일 크기가 0바이트인 빈 파일을 생성

```bash
touch file
```

<br>

#### file

- 파일의 종류 및 파일 속성값을 나타냄

<br>

#### find

- 하위 디렉터리까지 주어진 파일을 찾아 해당 경로를 표시

<br>

#### locate

- 파일의 위치를 찾음

---

## 텍스트 파일 관련 명령어

#### cat

- 파일의 전체 내용을 출력

```bash
cat /etc/passwd
```

<br>

#### head

- 파일의 앞부분을 지정한 만큼 출력

```bash
head /etc/passwd
```

<br>

#### tail

- 파일의 뒷부분을 지정한 만큼 출력

```bash
tail /etc/passwd
```

<br>

#### more

- 파일을 화면 단위로 끊어서 출력

```bash
# enter를 누르게되면 한 줄씩 내려감
more /etc/passwd
```

<br>

#### less

- 텍스트 파일을 한 번에 한 화면씩 나타냄

<br>

#### grep

- 파일에서 특정한 패턴 또는 정규 표현식으로 나타낸 단어를 찾음

<br>

#### wc

- 파일의 라인 수, 단어 수, 알파벳 수를 알려주는 명령어

<br>

#### sort

- 명령어 결과나 문서 내용을 정렬

<br>

#### cut

- 파일에서 특정 필드를 추출

<br>

#### split

- 하나의 파일을 여러 개의 작은 파일로 분리

---

## 파일 비교 명령어

#### diff

- 두개의 파일을 행 단위로 비교하여 다른 부분을 출력

<br>

#### cmp

- 두 개의 파일을 바이트 단위로 비교하여 출력

<br>

#### comm

- 두 개의 파일을 줄 단위로 비교하여 출력

## 리다이렉션과 정규 표현식

- 리다이렉션이라고 하는 특수문자를 이용해서 입,출력을 모니터가 아닌 다른 곳으로 변경해줄 수 있음

```bash
cat /etc/passwd | grep root

# 하드디스크에 남아있는 용량을 출력
df -h

# 내가 원하는 특정 문자의 라인만 출력
df -h | grep root

# 이 출력 결과를 특정 파일로 저장
df -h | grep root > disk
```
<br>

| 기호 | 의미 |
|-|-|
| ^ | 라인의 첫 글자 |
| $ | 라인의 끝 글자 |
| . | 한 글자 |
| * | * 이전의 글자나 정규 표현식이 0회 이상 반복 |
| [] | 대체 글자 목록을 []에 나열 |
| [^] | 대체 목할 글자 목록을 [^]에 나열 |
| + | + 이전의 글자나 정규 표현식이 0회 이상 반복 |
| ? | ? 기호 바로 이전 글자나 정규 표현식이 없거나 1회만 존재 |
| () | 부분 정규 표현식의 시작과 끝을 표시 |
| \| | \|로 구분된 단어들 중 최소 하나 존재 |
| {m,n} | {} 기호 바로 이전 글자나 정규 표현식이 m개 이상 n개 이하 반복 |
