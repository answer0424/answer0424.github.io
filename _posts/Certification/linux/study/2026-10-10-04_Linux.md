## 권한 및 그룹 설정

#### 소유권과 허가권

```text
- rw-rw-r--
```

- 첫번째 `-`은 파일의 종류를 나타내는 것으로 허가권과 관련이 없음
- 첫번째 3글자는 소유자의 허가권
- 두번째 3글자는 소유 그룹의 허가권
- 세번째 3글자는 일반 다른 사용자의 허가권

<br>

#### chown

- 소유자를 변경하는 명령어

<br>

#### chgrp

- 소유 그룹을 변경하는 명령어

<br>

#### chmod

- 허가권을 변경
- r: 읽기 권한(4) / w: 쓰기 권한(2) / x: 실행 권한(1)
- 숫자모드와 기호모드가 있음

<br>


| 대상 | 권한 | 권한 부여 여부 |
|-|-|-|
| 소유자, u | 읽기, r | 권한 부여, + |
| 관리그룹, g | 쓰기, w | 권한 회수, - |
| 나머지 사용자, o | 실행, x | |
| 모든 사용자, a | | |

```bash
# 소유자: rwx / 그룹: rw / 다른 사용자: r
chmod 764 file
chmod g+x file

chown root file
chgrp root file
```
