## 권한 및 그룹 설정

#### 소유권과 허가권

```text
- rw-rw-r--
```

- 첫번째 `-`은 파일의 종류를 나타내는 것으로 허가권과 관련이 없음
- 첫번째 3글자는 소유자의 허가권
- 두번째 3글자는 소유 그룹의 허가권
- 세번째 3글자는 일반 다른 사용자의 허가권

<br>

#### chown

- 소유자를 변경하는 명령어

<br>

#### chgrp

- 소유 그룹을 변경하는 명령어

<br>

#### chmod

- 허가권을 변경
- r: 읽기 권한(4) / w: 쓰기 권한(2) / x: 실행 권한(1)
- 숫자모드와 기호모드가 있음

<br>


| 대상 | 권한 | 권한 부여 여부 |
|-|-|-|
| 소유자, u | 읽기, r | 권한 부여, + |
| 관리그룹, g | 쓰기, w | 권한 회수, - |
| 나머지 사용자, o | 실행, x | |
| 모든 사용자, a | | |

```bash
# 소유자: rwx / 그룹: rw / 다른 사용자: r
chmod 764 file
chmod g+x file

chown root file
chgrp root file
```

## 허가권 관련 명령어

#### umask 명령어

- 파일(기본): 644
- 디렉토리(기본): 775
- umask는 022로 기본 설정되어 있고 변경을 하더라도 재부팅을 하게되면 022로 다시 원복됨

---

## 권한 및 특수 권한

#### 특수 권한

- SetUID(s) - 프로세스 실행 당시 소유자의 UID로 설정
- SetGID(s) - 프로세스 실행 당시 소유 그룹의 GID로 설정
- Sticky Bit(t) - 디렉터리 안의 내용은 해당 파일의 소유자나 root만이 변경 가능하게 설정

---

## 디스크 쿼터

#### 디스크 쿼터 개요 및 설정 방법

- 파일 시스템마다 사용자나 그룹이 생성할 수 있는 파일의 용량 및 개수를 제한하는 것
- /etc/fstab 또는 마운트 명령어로 파일시스템에서 쿼터 기능 활성화 후 사용

<br>

#### quotaoff

- 쿼터 서비스를 비활성화

<br>

#### quotacheck

- 파일 시스템의 디스크 사용 상태를 검색

<br>

#### edquota

- 편집기를 이용하여 디스크 사용량을 설정

<br>

#### setquota

- 사용자나 그룹에 디스크 사용량을 할당
