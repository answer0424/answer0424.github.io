## 특징

- 서버 사이드 HTML 렌더링
- 네츄럴 템플릿
- 스프링 통합 지원

## SSR
- 타임리프는 백엔드 서버에서 HTML을 동적으로 렌더링하는 용도

## 네츄럴 템플릿

- 타임리프는 순수 HTML을 최대한 유지하는 특징
- HTML을 유지하기 때문에 웹 브라우저에서 파일을 직접 열어도 내용을 확인할 수 있고 서버를 통해 뷰 템플릿을 거치면 동적으로 변경된 결과를 확인할 수 있음
- JSP를 포함한 다른 뷰 템플릿은 해당 파일을 열면 정상적인 HTML 결과를 확인할 수 없음
- 이렇게 순수 HTML을 유지하면서 뷰 템플릿을 사용할 수 있는 타임리프의 특징을 네츄럴 템플릿이라고 함

## HTML 엔티티

- HTML에서 사용하는 특수 문자를 HTML 엔티티로 변경하는 것을 이스케이프라고 함
- 타임리프가 제공하는 이런 것들을 위해 기본적으로 이스케이스를 제공
