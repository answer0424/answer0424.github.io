## 보안 문제

- 쿠키 값은 임의로 변경할 수 있음
  - 클라이언트 쿠키를 강제로 변경하면 다른 사용자가 됨
  - 실제 웹 브라우저 개발자 모드에서 변경할 수 있음
- 쿠키에 보관된 정보는 훔쳐갈 수 있음
  - 이 정보가 웹 브라우저에도 보관되고, 네트워크 요청마다 계속 클라이언트에서 서버로 전달


## 대안

- 쿠키에 중요한 값을 노출하지 않고 사용자 별로 예측 불가능한 임의의 토큰을 노출하고, 서버에서 토큰과 사용자 id를 매핑해서 인식
- 토큰은 해커가 임의의 값을 넣어도 찾을 수 없도록 예상 불가능하게 해야 함
- 토큰의 만료시간을 설정
